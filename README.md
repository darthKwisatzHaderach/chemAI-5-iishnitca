# ChemiAI — предсказание IC50, CC50 и SI

Самодостаточное решение задачи хемоинформатики: по молекулярным дескрипторам предсказываются три показателя активности против вируса гриппа.

| Показатель | Смысл |
|------------|--------|
| **IC50** | Концентрация (mM), при которой подавляется 50% вирусной активности |
| **CC50** | Концентрация (mM), при которой токсичны 50% клеток |
| **SI** | Selectivity index — индекс селективности |

**Метрика:** средний **RMSE** (root mean squared error, среднеквадратичная ошибка) по IC50, CC50 и SI.

## Подход

Используются **192 дескриптора RDKit** (из 214 после удаления константных колонок на train).

### Базовый ансамбль (все три таргета)

- **KMeans** (4 кластера) + градиентный boosting и **CatBoost** на кластерных признаках.
- Для **CC50** — **трансдуктивный kNN** (k nearest neighbors, k ближайших соседей): **PCA** (principal component analysis) на объединении train и test, затем поиск соседей.

### IC50

- Разностные признаки (гетероциклы vs гибкость/размер молекулы).
- **CatBoost** на полном наборе признаков — **20%** вклада в итоговое IC50.
- **LightGBM** — **59%** вклада; в каждом фолде к train добавляются молекулы из **ChEMBL** (вес **15%**).
- Два **kNN**-признака по ChEMBL (**k=4**): калиброванный (квантильное отображение на train) и сырой медианный.

### CC50

- kNN-признак по прокси-CC50 из ChEMBL (**k=6**, с калибровкой шкалы).

### SI

- Регрессия + смешивание с отношением CC50/IC50: **30%** предсказание модели, **70%** ratio (α=0.30).

### Валидация и предсказание test

- **5-fold CV** (cross-validation) → **OOF** (out-of-fold) на train.
- Test: усреднение по двум **seed** (42 и 7).

Конфигурация: `BEST_CFG` — kNN IC50 k=4, CC50 k=6, dual kNN по IC50.

Подробности, EDA и список отклонённых экспериментальных веток — в текстовых разделах ноутбука (§1–§6, §4.1).

## Воспроизведение

### 1. Окружение

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Рекомендуется Python 3.10–3.12 (для **RDKit**).

### 2. Запуск

1. Клонируйте репозиторий и перейдите в его корень (там, где лежит `solution.ipynb`).
2. В IDE или Jupyter выберите kernel из **`.venv`**.
3. Откройте **`solution.ipynb`**.
4. Выполните все ячейки **сверху вниз** (Run All):
   - сначала §7 «Приложение — код» (определения функций),
   - затем §8 (загрузка данных, обучение, формирование ответа).

### 3. Результат

- Файл **`submission.csv`** в корне репозитория: колонки `index`, `IC50`, `CC50`, `SI`.
- В §8.4 выводится **OOF**-метрика на train (ожидаемо **≈525 RMSE**; трансдуктивные признаки завышают локальную оценку).
